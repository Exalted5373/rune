- **Files dropped on a window work on Wayland.** winit 0.30 reports no file drags there, so a file manager's drag never reached `El::on_drop_files`. A Wayland window now binds its own `wl_data_device` on winit's display connection, dispatched on a thread of its own, and takes drags offering `text/uri-list` as macOS, Windows and X11 windows do: `on_drop_hover`, `on_drop_move`, the rejected callbacks and `Tx::drop_point` follow the drag at the position Wayland gives. It asks the source for a copy, so a move never deletes the dragged files.
